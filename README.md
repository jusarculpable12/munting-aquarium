# Munting Aquarium

A cozy Filipino aquarium game. Raise colorful fish and grow your little fish shop!

## How to play

- **Feed:** Tap the water to drop food. Watch each fish’s fullness—avoid overfeeding!
- **Care:** Change water and upgrade filtration to keep fish healthy.
- **Grow:** Earn visitor coins, buy fish and accessories, and unlock up to three tanks.
- **Breed & collect:** Keep a healthy adult pair with enough space for babies. Discover colors in the fish book and sell adult fish for coins.

Progress saves automatically in your browser. Fish care pauses while you’re away. Export a backup in Settings before clearing browser data.

## Built with

**Next.js · React · TypeScript · CSS · HTML Canvas** for the interface, aquarium, and animated fish. Saves use browser local storage.
